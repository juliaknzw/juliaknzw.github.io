[how i think]

code, story, trust.

three lenses I run every decision through, whichever hat I'm wearing that day.

code

systems should be boring in the best way — predictable, documented, easy to hand off to the next person, including future me.

story

a hook is a UX pattern. attention is earned in the first three seconds or not at all — the same rule applies to a landing page and a Reel.

trust

an audience — or a user, or a team — forgives a rough edge faster than an inconsistent voice. show up the same way, every time.
